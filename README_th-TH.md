## 🤔 What is Grok Imagine?

**Grok Imagine** is a video generation model by **xAI**, integrated into the Grok AI assistant on X (Twitter). It generates high-quality, cinematic videos from text prompts and images with stunning visual quality.

**Key Features:**
- 🎬 **Text-to-Video** — Generate videos from text descriptions
- 🖼️ **Image-to-Video** — Animate static images into dynamic videos
- ✂️ **Video Editing** — Edit and transform existing videos
- 🔊 **Auto Audio** — Automatic dubbing and background music
- 📐 **720p+ Resolution** — 10-15 seconds duration per clip
- ⚡ **Fast Generation** — Under 20 seconds generation time

> พรอมต์วิดีโอระดับ 4K แบบภาพยนตร์ สำหรับสร้างฉากฤดูร้อนที่เปี่ยมด้วยความทรงจำและเงียบสงบภายในบ้านชนบทเกาหลีแบบดั้งเดิม โดยมีแสงแดด แตงโมหั่นชิ้นสามเหลี่ยม และพัดลมตั้งพื้นแบบหมุนส่าย

#### 📝 Prompt

```
วิดีโอฤดูร้อนความยาว 10 วินาทีที่ให้ความรู้สึกสดใสและสดชื่น ภายในห้องนั่งเล่นของบ้านไม้เก่าสไตล์ชนบทเกาหลี แสงแดดที่สว่างและสะอาดตาลอดผ่านประตูและหน้าต่างที่เปิดกว้าง พื้นไม้และผนังไม้เก่าแก่สร้างบรรยากาศบ้านชนบทที่อบอุ่นและชวนให้คิดถึงวันวาน โดยรวมแล้วให้ความรู้สึกเหมือนยามบ่ายในฤดูร้อนที่สว่างไสวและโปร่งสบาย

ประตูเปิดกว้างออกสู่ภายนอก เห็นต้นไม้และใบไม้สีเขียวสดกำลังไหวเอนตามสายลมเบาๆ บรรยากาศภายนอกดูปลอดโปร่งและเป็นสีฟ้าคราม สงบเงียบเหมือนยามบ่ายในฤดูร้อนของชนบท

มีถาดโลหะทรงกลมวางอยู่บนโต๊ะไม้เตี้ยๆ โดยมีชิ้นแตงโมวางอยู่ภายในถาดเท่านั้น ไม่ได้วางบนโต๊ะโดยตรง มีชิ้นแตงโมสามเหลี่ยมสดๆ ประมาณ 5 ถึง 6 ชิ้นจัดวางไว้อย่างเป็นระเบียบในถาด แตงโมแต่ละชิ้นไม่ใช่รูปครึ่งวงกลม แต่เป็นชิ้นสามเหลี่ยมทั่วไปที่มีปลายแหลมและเปลือกสีเขียวสั้นๆ อยู่ด้านล่าง เมื่อมองจากมุมกล้อง เนื้อสีแดงจะดูเป็นรูปสามเหลี่ยมที่ชัดเจน และมีเปลือกสีเขียวติดอยู่ตามขอบด้านล่างของสามเหลี่ยมอย่างเป็นธรรมชาติ แตงโมมีความหนาไม่มาก ดูบางและสดใหม่ เผยให้เห็นเนื้อสีแดงฉ่ำ เมล็ดสีดำเล็กๆ และให้ความรู้สึกถึงแตงโมฤดูร้อนที่เย็นสดชื่น

ข้างถาดมีสมุดบันทึกภาพวาดฤดูร้อนที่วาดด้วยดินสอสีวางอยู่ แต่ข้อความในนั้นอ่านไม่ออก มีดินสอสีหลายแท่งวางอยู่รอบๆ สมุดบันทึกอย่างเป็นธรรมชาติ ดูเหมือนมีการใช้งานจริงมากกว่าจะวางระเกะระกะ

พัดลมไฟฟ้าเก่าๆ วางอยู่บนพื้นไม้ข้างโต๊ะ กำลังหมุนส่ายไปมาอย่างช้าๆ พร้อมใบพัดที่หมุนอยู่ สายลมจากพัดลมทำให้ผ้าม่านและหน้ากระดาษของสมุดบันทึกขยับเล็กน้อย แม้จะเป็นวันฤดูร้อนที่ร้อนอบอ้าวด้วยแสงแดด แต่ภายในห้องกลับให้ความรู้สึกเย็นสบายและผ่อนคลาย

บรรยากาศชวนคิดถึงของบ้านชนบทเกาหลี แสงแดดสดใส ต้นไม้สีเขียวสด ห้องนั่งเล่นไม้ที่อากาศถ่ายเทสะดวก เงาที่นุ่มนวล พื้นผิวที่สมจริง ยามบ่ายฤดูร้อนที่เงียบสงบ บรรยากาศที่ผ่อนคลายและเงียบสงบ ระดับ 4K แบบภาพยนตร์ แสงธรรมชาติ แตงโมหั่นชิ้นสามเหลี่ยมบนถาดโลหะและสมุดบันทึกภาพ กล้องค่อยๆ เคลื่อนเข้าหาพัดลมตั้งพื้น ไม่มีผู้คน
```

### หนูบาทหลวงคาทอลิกในบรูคลิน

![English](https://img.shields.io/badge/lang-English-blue)

> พรอมต์วิดีโอแนวภาพยนตร์สำหรับฉากที่สมจริงราวกับภาพถ่าย นำเสนอหนูในชุดบาทหลวงที่กำลังเดินทางผ่านโลกอันวุ่นวายและกว้างใหญ่ของบรูคลิน

#### 📝 Prompt

```
ฉากภาพยนตร์ความยาว 15 วินาที สมจริงระดับภาพถ่ายขั้นสูง ความสมจริงระดับ Pixar พร้อมแสงแบบไลฟ์แอ็กชัน ความละเอียด 4K ระยะชัดลึกตื้น และการเคลื่อนไหวของกล้องที่เป็นธรรมชาติ

หนูนาตัวจิ๋วสีเทาในชุดบาทหลวงคาทอลิกผู้ถ่อมตน สวมชุดคาสซ็อกสีดำที่ตัดเย็บมาอย่างพอดีตัวพร้อมปกคอเสื้อแบบโรมันขนาดจิ๋วสำหรับหนู เขาถือกระเป๋าสะพายหนังใบเล็กที่เก่าคร่ำซึ่งเต็มไปด้วยหนังสือสวดมนต์ขนาดจิ๋ว และรีบเร่งด้วยความมุ่งมั่นไปตามท้องถนนที่ดูใหญ่โตเกินจริงของบรูคลิน นิวยอร์ก

กล้องเริ่มที่ระดับสายตาของหนู โดยมีรองเท้ามนุษย์ขนาดมหึมาเดินผ่านไปอย่างรวดเร็วราวกับตึกที่เคลื่อนที่ได้ รถแท็กซี่สีเหลืองคำรามอยู่เหนือหัว แรงสั่นสะเทือนจากรถไฟใต้ดินสัมผัสได้ผ่านทางเท้า ไอระเหยลอยขึ้นมาจากตะแกรงบนถนน ก่อตัวเป็นกลุ่มควันขนาดใหญ่รอบตัวเขา แก้วกาแฟ หน้าหนังสือพิมพ์ และใบไม้ร่วงหมุนวนไปในอากาศราวกับวัตถุขนาดยักษ์ในโลกของเขา

บาทหลวงตัวน้อยหลบหลีกล้อจักรยาน นกพิราบ แอ่งน้ำฝนขนาดเท่าทะเลสาบ และเงาของผู้คนที่เร่งรีบอย่างชำนาญ โดยยังคงความสงบและร่าเริงอยู่เสมอ แสงแดดสะท้อนความอบอุ่นลงบนตึกแถวอิฐสีน้ำตาล (brownstones) ในขณะที่เสียงระฆังโบสถ์ดังแว่วมาแต่ไกล

กล้องติดตามเขาไปจนถึงตึกแถวอิฐสีน้ำตาลเก่าแก่แห่งหนึ่งในบรูคลิน ที่ฐานของบันไดหินกว้างซึ่งนำไปสู่ประตูหน้าบ้าน มีโบสถ์ไม้ทรงโค้งขนาดจิ๋วที่สร้างขึ้นในฐานรากใต้บันได มีหน้าต่างกระจกสี ระฆังทองเหลืองขนาดเล็ก กระถางดอกไม้ และโคมไฟส่องสว่างเหนือทางเข้า

หนูบาทหลวงยิ้มด้วยความพึงพอใจอย่างเงียบๆ ไขประตูไม้บานเล็กด้วยกุญแจโบราณ ก้าวเข้าไปข้างใน และสั่นระฆังโบสถ์เล็กๆ อย่างแผ่วเบา ขณะที่แสงสีทองอบอุ่นสาดส่องออกมาบนทางเท้า ในขณะที่โลกอันวุ่นวายของมนุษย์ยังคงดำเนินต่อไปโดยไม่รับรู้ถึงสิ่งที่เกิดขึ้นเบื้องล่าง

มีความเป็นภาพยนตร์สูง ซาบซึ้งใจ มีความแปลกใหม่แต่สมจริง พื้นผิวที่สมจริง บรรยากาศบรูคลินที่แท้จริง การเล่าเรื่องที่เปี่ยมด้วยอารมณ์ การเคลื่อนกล้องที่นุ่มนวล ไม่มีบทสนทนา มีเพียงเสียงบรรยากาศของเมืองที่เป็นธรรมชาติเท่านั้น
```
