## 🤔 What is Grok Imagine?

**Grok Imagine** is a video generation model by **xAI**, integrated into the Grok AI assistant on X (Twitter). It generates high-quality, cinematic videos from text prompts and images with stunning visual quality.

**Key Features:**
- 🎬 **Text-to-Video** — Generate videos from text descriptions
- 🖼️ **Image-to-Video** — Animate static images into dynamic videos
- ✂️ **Video Editing** — Edit and transform existing videos
- 🔊 **Auto Audio** — Automatic dubbing and background music
- 📐 **720p+ Resolution** — 10-15 seconds duration per clip
- ⚡ **Fast Generation** — Under 20 seconds generation time

### การจำลองผู้ประกาศข่าวระดับมืออาชีพ

![English](https://img.shields.io/badge/lang-English-blue)

> คำสั่ง (Prompt) สำหรับวิดีโอผู้ประกาศข่าวที่กำลังรายงานเรื่องการเติบโตของเศรษฐกิจโลก พร้อมคำแนะนำโดยละเอียดเกี่ยวกับสีหน้าและน้ำเสียง

#### 📝 Prompt

```
ผู้ประกาศข่าวหญิงระดับมืออาชีพในสตูดิโอที่สะอาดตา ถ่ายภาพแบบครึ่งตัว (เห็นศีรษะและไหล่) จัดองค์ประกอบภาพไว้ตรงกลาง เธอมองตรงมาที่กล้องด้วยท่าทางที่มั่นใจ

* สีหน้า: สงบ สุขุม ดูจริงจังเล็กน้อยแต่ให้ความรู้สึกน่าเชื่อถือ

* การเคลื่อนไหว: พยักหน้าเล็กน้อยและกะพริบตาอย่างเป็นธรรมชาติขณะพูด

* การขยับของใบหน้า: คิ้วขยับเล็กน้อยเมื่อเน้นคำว่า “ชะลอตัว” (slowing) และ “ความเสี่ยงด้านเงินเฟ้อ” (inflation risks) และมีสายตาที่มั่นใจนุ่มนวลเมื่อพูดคำว่า “ระมัดระวัง” (cautious)

* น้ำเสียง: ชัดเจน มั่นคง ด้วยสำเนียงการอ่านข่าวระดับสากลที่เป็นกลาง

* แสง: แสงสตูดิโอแบบนุ่มนวลและมีทิศทาง พร้อมเงาที่ดูละมุน ช่วยขับสีผิวให้ดูเป็นธรรมชาติ

* พื้นหลัง: ห้องข่าวสไตล์มินิมอลที่ดูทันสมัย หรือฉากหลังแบบไล่เฉดสีนุ่มนวล (โทนสีฟ้าเย็นหรือโทนสีกลาง)

* สไตล์: ลุคผู้ประกาศข่าวที่ดูเนี้ยบ คุณภาพระดับงานโปรดักชันชั้นนำ

บทพูด: “Global growth is slowing, while inflation risks remain. Central banks stay cautious amid ongoing uncertainty.”
```
