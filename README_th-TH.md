## 🤔 What is Grok Imagine?

**Grok Imagine** is a video generation model by **xAI**, integrated into the Grok AI assistant on X (Twitter). It generates high-quality, cinematic videos from text prompts and images with stunning visual quality.

**Key Features:**
- 🎬 **Text-to-Video** — Generate videos from text descriptions
- 🖼️ **Image-to-Video** — Animate static images into dynamic videos
- ✂️ **Video Editing** — Edit and transform existing videos
- 🔊 **Auto Audio** — Automatic dubbing and background music
- 📐 **720p+ Resolution** — 10-15 seconds duration per clip
- ⚡ **Fast Generation** — Under 20 seconds generation time

### แอนิเมชันชุดแต่งงานเทพธิดาสามมิติ

![English](https://img.shields.io/badge/lang-English-blue)

> พรอมต์ที่มีความซับซ้อนและรายละเอียดสูงสำหรับการสร้างแอนิเมชันสามมิติแนวตั้งของเทพธิดาในพระราชวังสีขาว ซึ่งปรับแต่งมาเพื่อการเคลื่อนไหวของวิดีโอคุณภาพสูง

#### 📝 Prompt

```
แอนิเมชัน 3D สเตอริโอสโคปิกแนวตั้งสัดส่วน 9:16 ที่น่าทึ่งของหญิงสาวดุจเทพธิดายืนหันหลังในโถงพระราชวังสีขาวอันงดงาม เธอสวมชุดแต่งงานลูกไม้สีขาวเปิดไหล่ที่เก็บรายละเอียดอย่างประณีต พร้อมงานปักสีขาวน้ำแข็งเหลือบเงิน ชายกระโปรงยาวลากพื้น และผ้าคลุมหน้าโปร่งแสงที่ทิ้งตัวลงบนผมเปียสีทองประดับด้วยดอกกุหลาบสีขาว สายลมอ่อนๆ พัดพาให้ผ้าคลุมหน้า ชายกระโปรง และระบายลูกไม้อันละเอียดอ่อนพลิ้วไหวและหมุนวนด้วยฟิสิกส์ที่สมจริงดั่งมีชีวิต พร้อมพื้นผิว 3D ที่สัมผัสได้ชัดเจน เนื้อผ้าสะบัดและไหลลื่นในรูปแบบสโลว์โมชันที่นุ่มนวลและชวนหลงใหล

ระยะชัดลึกที่ลึกเป็นพิเศษและมิติเชิงลึกแบบสเตอริโอสโคปิกที่ซ้อนทับกัน: ฉากหน้ามีละอองลูกไม้สีขาวน้ำแข็งเหลือบเงิน กลีบกุหลาบ และหยดคริสตัลขนาดเล็กที่ลอยอยู่อย่างไร้น้ำหนักและกระเซ็นผ่านหน้ากล้องอย่างแผ่วเบา ฉากกลางเผยให้เห็นหญิงสาวในรายละเอียดที่ส่องสว่าง ฉากหลังเผยให้เห็นเสาหินอ่อนสีขาวสูงตระหง่านประดับด้วยดอกกุหลาบสีขาวที่ทิ้งตัวลงมา พื้นที่ขัดเงาสะท้อนแสง บัลลังก์ทองคำอันวิจิตรที่มีร่างในชุดคลุมสีเข้มนั่งอยู่ และยอดปราสาทคริสตัลที่อยู่ไกลออกไปภายใต้พระจันทร์เต็มดวงขนาดใหญ่ในท้องฟ้ายามสนธยาที่เต็มไปด้วยดวงดาว หมอกสีเงินนุ่มนวลและลำแสงโฮโลกราฟิกนีออนจางๆ ตัดผ่านอากาศ สร้างเลเยอร์ความลึกแบบพารัลแลกซ์ที่ชัดเจน มีลวดลายใบไม้และดอกกุหลาบที่ล่องลอยอย่างแผ่วเบาผ่านฉาก

```
ภาพสไตล์สารคดีในจัตุรัสคนเดินในยุโรปที่มีเมฆมากบนพื้นหิน ชายผู้มีเมตตาสวมเสื้อแจ็คเก็ตผ้าสักหลาดลายตารางสีน้ำตาลขาวทับเสื้อยืดสีขาวและกางเกงยีนส์สีเข้ม ค่อยๆ คุกเข่าลงและจับนกพิราบที่อยู่บนพื้นอย่างเบามือ กล้อง 4K แบบถือถ่ายสไตล์ภาพยนตร์เคลื่อนที่เข้าไปใกล้ช้าๆ แสงธรรมชาติจากกลางวัน ฉากหลังเบลอละมุน พื้นผิวสมจริง
