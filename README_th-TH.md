## 🤔 What is Grok Imagine?

**Grok Imagine** is a video generation model by **xAI**, integrated into the Grok AI assistant on X (Twitter). It generates high-quality, cinematic videos from text prompts and images with stunning visual quality.

**Key Features:**
- 🎬 **Text-to-Video** — Generate videos from text descriptions
- 🖼️ **Image-to-Video** — Animate static images into dynamic videos
- ✂️ **Video Editing** — Edit and transform existing videos
- 🔊 **Auto Audio** — Automatic dubbing and background music
- 📐 **720p+ Resolution** — 10-15 seconds duration per clip
- ⚡ **Fast Generation** — Under 20 seconds generation time

### ตัวหมากรุกโชงิที่เปลี่ยนร่างเป็นมังกรในอวกาศ

![日本語](https://img.shields.io/badge/lang-日本語-green)

> พรอมต์ที่มีรายละเอียดสูงสำหรับ Grok Imagine เพื่อสร้างวิดีโอแอนิเมชันสั้นความยาว 15-20 วินาที วิดีโอนี้นำเสนอตัวหมากโชงิ (หมากรุกญี่ปุ่น) ที่เรียกว่า 'ฮิฉะ' (เรือ) กำลังเปลี่ยนร่างเป็นมังกรและบินออกไปในอวกาศ โดยเรนเดอร์ในสไตล์แฟนตาซีไซไฟผสมผสานกับสีน้ำและละอองแสง พรอมต์นี้ประกอบด้วยคำอธิบายฉากเฉพาะสำหรับช่วงเริ่มต้น ช่วงกลาง และช่วงไคลแมกซ์

#### 📝 Prompt

```
• ชื่อเรื่อง: "การอัญเชิญมังกรแห่งสายน้ำใส ~จาก 4-1 ฮิฉะ สู่ 8-3 ริว ของ Amaterasu Okami Kaioshin~"
• สไตล์: สไตล์แฟนตาซีไซไฟผสมผสานกับสีน้ำและละอองแสง (เน้นความอ่อนโยนและสวยงามราวกับสายน้ำที่ไหลริน)
• ความยาว: วิดีโอแอนิเมชันสั้นประมาณ 15-20 วินาที
• จุดกำกับทิศทาง:
• ช่วงเริ่มต้น: กระดานโชงิที่ดูเหมือนกลุ่มดาว 81 ช่องลอยอยู่ในอวกาศอันเงียบสงบ
• ช่วงกลาง: ช่วงเวลาที่สมดุลถูกทำลายด้วยการวางเบี้ยที่ตำแหน่ง 2-2 ซึ่งแสดงออกมาอย่างงดงามราวกับระลอกคลื่นแห่งแสง
• ช่วงไคลแมกซ์: 4-1 ฮิฉะ ที่อยู่ไกลออกไปเคลื่อนที่ด้วยความเร็วสูงพร้อมหางแสง → เปลี่ยนร่างเป็น 7-1 ริว → เงิน...
```
