## 🤔 What is Grok Imagine?

**Grok Imagine** is a video generation model by **xAI**, integrated into the Grok AI assistant on X (Twitter). It generates high-quality, cinematic videos from text prompts and images with stunning visual quality.

**Key Features:**
- 🎬 **Text-to-Video** — Generate videos from text descriptions
- 🖼️ **Image-to-Video** — Animate static images into dynamic videos
- ✂️ **Video Editing** — Edit and transform existing videos
- 🔊 **Auto Audio** — Automatic dubbing and background music
- 📐 **720p+ Resolution** — 10-15 seconds duration per clip
- ⚡ **Fast Generation** — Under 20 seconds generation time

### วิดีโอการแข่งรถแบบแบ่งหน้าจอที่ซิงโครไนซ์กัน

![日本語](https://img.shields.io/badge/lang-日本語-green)

> คำสั่ง (Prompt) ที่ครอบคลุมสำหรับการสร้างวิดีโอแบบแบ่งหน้าจอที่ซิงโครไนซ์กันของรถสปอร์ตที่กำลังดริฟต์บนเส้นทางภูเขาในญี่ปุ่น โดยแสดงทั้งมุมมองจากภายในห้องโดยสารของผู้ขับขี่และมุมมองกล้องไล่ตามจากภายนอก

#### 📝 Prompt

```
หน้าจอมีการจัดวางแบบแบ่งครึ่งซ้ายและขวา ทั้งสองด้านจับภาพช่วงเวลาเดียวกันจากมุมกล้องที่แตกต่างกัน โดยแสดงรถคันเดียวกัน เข้าโค้งเดียวกัน และอยู่ในช่วงเวลาเดียวกัน

[หน้าจอซ้าย]
กล้องภายในรถมุมมองผู้ขับขี่ ภายในรถสปอร์ตที่มีโครงเหล็กนิรภัย (Roll cage) ตัวละครนั่งอยู่ในที่นั่งคนขับโดยใช้มือทั้งสองข้างจับพวงมาลัย ขับขี่ด้วยความเร็วสูงบนเส้นทางภูเขาในญี่ปุ่น กำลังเข้าและเลี้ยวผ่านโค้งหักศอก สายตาจดจ้องไปในทิศทางที่รถกำลังเคลื่อนที่ด้วยสีหน้าที่จริงจังและมีสมาธิ แรงเหวี่ยงหนีศูนย์กลางส่งผลต่อร่างกาย ทำให้ไหล่และเส้นผมพริ้วไหวออกไปด้านข้างเล็กน้อย เสื้อผ้าและเส้นผมเคลื่อนไหวอย่างเป็นธรรมชาติไปตามการเคลื่อนที่ของรถ มีรายละเอียดของเบาะบัคเก็ตซีท (Bucket seats) เกจวัดต่างๆ และการสั่นของกล้องที่เป็นธรรมชาติซึ่งสอดคล้องกับการสั่นสะเทือนของตัวรถ

[หน้าจอขวา]
กล้องไล่ตามมุมมองบุคคลที่สามที่ติดตามรถคันเดียวกันจากด้านหลังและด้านบนเล็กน้อย ทิวทัศน์ที่สมจริงของเส้นทางภูเขาในญี่ปุ่นที่รายล้อมไปด้วยป่าไม้ มีราวกันตกและเส้นแบ่งเลน รถกำลังเลี้ยวผ่านโค้งหักศอกเดียวกัน แสดงให้เห็นการถ่ายเทน้ำหนักของตัวรถ ยางยึดเกาะพื้นถนนอย่างแน่นหนา และระบบกันสะเทือนยุบตัวอย่างเป็นธรรมชาติ ถ่ายทอดการเข้าโค้งด้วยความเร็วสูง ความรู้สึกถึงความเร็ว และความมีชีวิตชีวา

[คำแนะนำในการซิงโครไนซ์]
หน้าจอซ้ายและขวาไม่ใช่ฉากที่แตกต่างกัน การหมุนพวงมาลัยบนหน้าจอซ้ายและการเคลื่อนที่ของรถบนหน้าจอขวาจะต้องตรงกันอย่างสมบูรณ์ เพื่อสื่อให้เห็นชัดเจนว่ากล้องสองตัวกำลังถ่ายทำในช่วงเวลาเดียวกัน โดยแสดงลำดับการเข้าโค้งอย่างต่อเนื่องโดยไม่มีการตัดฉากหรือเปลี่ยนมุมกล้อง

[ขั้นตอนสุดท้าย]
รถเร่งความเร็วออกจากโค้ง บนหน้าจอซ้ายผู้ขับขี่คืนพวงมาลัยกลับมาที่ตำแหน่งตรงขณะเร่งความเร็ว บนหน้าจอขวารถเคลื่อนที่อย่างมั่นคงไปยังส่วนถัดไป มีการเร่งความเร็วที่ราบรื่น พฤติกรรมของรถที่สมจริง และให้ความรู้สึกดื่มด่ำเหมือนการถ่ายทอดสดการแข่งขันมอเตอร์สปอร์ต ตัวละครสไตล์อนิเมะคุณภาพสูง ฉากหลังคุณภาพสูง และการถ่ายทอดรายละเอียดรถที่สมจริง เหมือนฉากหนึ่งจากภาพยนตร์
```

### วิดีโอภาพยนตร์ปลาทะเลลึกเรืองแสง

![English](https://img.shields.io/badge/lang-English-blue)

> พรอมต์วิดีโอแนวภาพยนตร์ที่มีรายละเอียดสำหรับฉากสไตล์สารคดีธรรมชาติ นำเสนอภาพปลาเรืองแสงสุดน่าเกรงขามในมหาสมุทรลึก

