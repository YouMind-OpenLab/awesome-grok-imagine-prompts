## 🤔 What is Grok Imagine?

**Grok Imagine** is a video generation model by **xAI**, integrated into the Grok AI assistant on X (Twitter). It generates high-quality, cinematic videos from text prompts and images with stunning visual quality.

**Key Features:**
- 🎬 **Text-to-Video** — Generate videos from text descriptions
- 🖼️ **Image-to-Video** — Animate static images into dynamic videos
- ✂️ **Video Editing** — Edit and transform existing videos
- 🔊 **Auto Audio** — Automatic dubbing and background music
- 📐 **720p+ Resolution** — 10-15 seconds duration per clip
- ⚡ **Fast Generation** — Under 20 seconds generation time

```
[Objetivo de Geração]
Gere um vídeo contínuo e de altíssima qualidade mostrando uma sequência de transformação de outro nível, na qual uma simples folha de papel evolui até se tornar um foguete completo da SpaceX.

[Roteiro do Evento]
No início: uma única folha de papel branco e limpo repousa plana e imóvel sobre uma superfície escura, sob uma iluminação suave de estúdio.

#### 📝 Prompt

```
[Objetivo de Geração]
Gere um vídeo de transformação e evolução de alto nível da mulher. [Guião de Eventos]
No início: A mulher está de pé, calma, segurando uma garrafa de água transparente. Um coelho descansa perto dos seus pés.
