## 🤔 什麼是 Grok Imagine？

**Grok Imagine** 是 **xAI** 推出的視頻生成模型，集成在 X（Twitter）平台的 Grok AI 助手中。它可以通過文本提示詞和圖片生成高質量、電影級的視頻。

**Key Features:**
- 🎬 **文本生成視頻** — 根據文字描述生成視頻
- 🖼️ **圖片生成視頻** — 將靜態圖片轉化為動態視頻
- ✂️ **視頻編輯** — 編輯和轉換現有視頻
- 🔊 **自動音頻** — 自動配音和背景音樂
- 📐 **720p+ 分辨率** — 每個片段 10-15 秒時長
- ⚡ **快速生成** — 20 秒內完成生成

徹底分析附帶的參考圖像與 SNS 個人檔案，完全原創地設計一個「角色實際居住的房間」，並生成影片。

[10 秒影片結構 (連續一鏡到底)]

真實的室內場景。一隻人手小心地取下牆上的插座蓋板。透過寫實的真人微距攝影捕捉塑膠、壁紙和指尖的質感。從蓋板後方，透出帶有房間主題色的微弱暖光。

■ 8-10 秒 (餘韻)：
角色注意到鏡頭，短暫地看向它，並給出一個小巧迷人的反應。以令人想再次窺探的 lingering feeling 作結，留下溫暖的房間氛圍和細微的動作。
