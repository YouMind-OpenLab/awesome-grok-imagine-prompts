## 🤔 Grok Imagine이란?

**Grok Imagine**은 **xAI**가 개발한 비디오 생성 모델로, X(Twitter) 플랫폼의 Grok AI 어시스턴트에 통합되어 있습니다. 텍스트 프롬프트와 이미지로 고품질 시네마틱 비디오를 생성합니다.

**Key Features:**
- 🎬 **텍스트에서 비디오** — 텍스트 설명으로 비디오 생성
- 🖼️ **이미지에서 비디오** — 정적 이미지를 동적 비디오로 변환
- ✂️ **비디오 편집** — 기존 비디오 편집 및 변환
- 🔊 **자동 오디오** — 자동 더빙 및 배경 음악
- 📐 **720p+ 해상도** — 클립당 10-15초 길이
- ⚡ **빠른 생성** — 20초 이내 생성 완료

### Grok Imagine 기계 및 영적 생명체 프롬프트

![日本語](https://img.shields.io/badge/lang-日本語-green)

> Grok Imagine에서 고품질 비디오 생성을 위해 설계된, 기계 네온 여우와 스테인드글라스 정령을 생성하기 위한 상세한 시각적 묘사 세트입니다.

#### 📝 프롬프트

```
네온 여우 (기계 여우)
콘셉트: 민첩함과 지혜를 상징하는 작은 기계 여우. 고속 통신을 위한 파트너 역할을 합니다.
세부 묘사: 복잡한 기계 부품과 노란색 네온 튜브로 구성된 작은 여우입니다. 몸의 일부는 투명하여 내부의 빛나는 데이터 흐름을 보여줍니다. 시야에 들어오는 것을 데이터로 포착하기 위한 렌즈 형태의 눈을 가지고 있습니다.
```
