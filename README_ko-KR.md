## 🤔 Grok Imagine이란?

**Grok Imagine**은 **xAI**가 개발한 비디오 생성 모델로, X(Twitter) 플랫폼의 Grok AI 어시스턴트에 통합되어 있습니다. 텍스트 프롬프트와 이미지로 고품질 시네마틱 비디오를 생성합니다.

**Key Features:**
- 🎬 **텍스트에서 비디오** — 텍스트 설명으로 비디오 생성
- 🖼️ **이미지에서 비디오** — 정적 이미지를 동적 비디오로 변환
- ✂️ **비디오 편집** — 기존 비디오 편집 및 변환
- 🔊 **자동 오디오** — 자동 더빙 및 배경 음악
- 📐 **720p+ 해상도** — 클립당 10-15초 길이
- ⚡ **빠른 생성** — 20초 이내 생성 완료

> 예수 그리스도의 사랑과 희생, 그리고 부활을 기리며 가족과 친구, 모든 이들을 위한 축복의 기도를 담은 부활절 기념 영상 생성용 Grok Imagine 스페인어 프롬프트입니다.

#### 📝 프롬프트

```
행복한 부활절입니다.

오늘 우리는 예수 그리스도와 그분의 사랑, 희생, 그리고 부활을 기억합니다.
예수님께서는 우리를 구원하기 위해 목숨을 바치셨고, 사흘 만에 영광스럽게 부활하셨습니다.

사랑하는 예수님, 우리의 가족과 친구, 그리고 모든 이들에게 축복을 내려 주시옵소서...
```
