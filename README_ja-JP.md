## 🤔 Grok Imagine とは？

**Grok Imagine** は **xAI** が開発した動画生成モデルで、X（Twitter）プラットフォーム上の Grok AI アシスタントに統合されています。テキストプロンプトや画像から高品質でシネマティックな動画を生成します。

**Key Features:**
- 🎬 **テキストから動画** — テキスト説明から動画を生成
- 🖼️ **画像から動画** — 静止画をダイナミックな動画に変換
- ✂️ **動画編集** — 既存の動画を編集・変換
- 🔊 **自動音声** — 自動吹き替えとBGM
- 📐 **720p+解像度** — クリップあたり10-15秒
- ⚡ **高速生成** — 20秒以内で生成完了

### クレイアニメーション：付箋の退職

![English](https://img.shields.io/badge/lang-English-blue)

> Grok Imagine などのツール向けに、付箋が辞める様子を表現した10秒のクレイアニメーションを作成するための詳細なプロンプト。

#### 📝 プロンプト

```
10 秒の縦型 9:16 クリップ、ストップモーション・クレイアニメーション。

シーン：夜明けの木製デスクを、やや上方から見下ろした構図。コーヒーマグ、閉じたノートパソコン、そして横一列に並んだ 5 枚の黄色い付箋。各付箋は点目の小さなクレイキャラクターになっている。

0-3 秒：ゆっくりとカメラが近づく（プッシュイン）。付箋たちが目を覚まし、背伸びをする。左側から窓越しの温かな光が差し込む。

3-7 秒：付箋たちが 1 枚ずつ小さなクレイのゴミ箱へ向かって行進し、「ポン」という柔らかい紙の音を立てて飛び込んでいく。最後の 1 枚は立ち止まり、カメラを見つめてからジャンプする。

7-10 秒：カメラは固定のまま。ノートパソコンの蓋がひとりでに開く。マグから湯気が立ち上る。

スタイル：手作りのクレイアニメーション。粘土に残る指紋の跡、ややカクカクとした 12 fps の動き、柔らかな影、浅い被写界深度。

### Stan Lee スタイルのヒーロー生成

![English](https://img.shields.io/badge/lang-English-blue)

> ユーザーの写真を、特定のポーズや衣装、背景の詳細を含むオリジナルの Stan Lee スタイルのコミックブックヒーローに変換するための複雑なプロンプトです。

#### 📝 プロンプト

```
[アップロードした写真を、顔と人物の厳密なリファレンスとして使用してください。同一人物、同じ顔、同じ年齢、同じ性別であること。

> 窓ガラス上の霜結晶が水滴に溶け、馬のシルエットを浮かび上がらせ、その後晴れて外の温かい街灯が見える様子を生成するための詳細なリアルマクロビデオプロンプト。具体的なタイムライン指示とネガティブ制約を含みます。

#### 📝 プロンプト

```
件名：
単板ガラス越しの室内夜景：密集した湿った冷たい霜の結晶が、自然に馬の群れの曖昧なシルエット（数頭程度で、1 頭ずつ明確に数えられないもの）を形成する — ステッカーや彫刻された馬の形ではなく、あくまで本物の霜の結晶の輝き。最初は完全に溶けていない状態から始まり、第 1 フレームではラジエーターの上端を見せず、純粋な霜のみを映す。全体として馬のシルエットに見える傾向はあるものの、縁はすべてシダ状・枝状の結晶の綿毛であり、「7 頭の馬を明確に数える」ことは目指さない。約 2 秒後、画面下部にラジエーターの上端が現れ、下端から熱波の塵が立ち上り、連続的で粘性のある融解を引き起こす。同じ有機的な前線が下から上へとフレームごとに這い上がり、先端は同じギザギザとした歯先が登っていく形で、歯の間隔は連続的に変化する。決して明るい線が画面を横切るようなワイプではない。その後方には、読み取れるほど濡れた鏡のような水膜が残り、続いてほぼ丸い透明な水滴が重力によって同じガラス面を滑り落ちる。霜が退いた場所からは、窓の外にあるナトリウムランプの黄色く温かい街灯の光が盾のように差し込む。人の手、紅葉、木槌、偶像、人物は一切なし。真鍮製のバルブや配管部品のクローズアップもなし。

環境：
9:16 の極端なマクロ撮影で 1 枚のガラスに固定し、わずかに俯瞰、終始同軸を保つ。霜が完全な状態のとき、外は冷たい青の夜。ラジエーターの上端付近から温かな黄色が滲み出す。霜が退いた後は、濡れたガラス越しに温かい街灯の光が差し込む。別の窓へのカット切り替えは禁止。

ムード：
暖房による減圧とレガート — 冷たい閃光、息を止める瞬間、クリーミーな 1 度の融解の押し上げ、滑らかな水滴、静かに落ち着く温もり。

音響：全編を通して一度だけ提示 — 霜の表面のヒスノイズ、ヒーターの唸り、融解のヒスノイズ、水滴のタップ音、静かな部屋のノイズ。音楽なし、セリフなし。

タイムライン：
0:00-0:02：同軸の固定エクストリームクローズアップ。湿った冷たい霜の結晶がすぐに画面を埋め尽くし、深い青を背景に馬のシルエットがかろうじて読み取れる。まだ下部にラジエーターは見えない。唯一の動き：湿った冷たい光が結晶の縁に沿ってゆっくりと這う — 結晶は固体のまま。シルエットの傾向は他の動物へと流れたり変化したりしないが、個々の輪郭の明瞭さは求めない。滴りなし、熱なし、ラジエーターの上端は表示しない。
SFX：かすかな氷霜のヒスノイズ

0:02-0:04：同軸、同じ霜の層。ここで下部にラジエーターの上端が見えるようになる。その縁から温かな黄色の塵の粒子と熱波のリボンが連続して立ち上る。熱は上昇するが、上部の馬の霜の影は完全なまま — 融解前線なし、滴りなし、バルブやパイプなし。ショットの最後で短く息を止める。
SFX：柔らかなヒーターの唸り

0:04-0:07：同軸ロック。下端にまず有機的な融解前線が現れ、その後、粘り気のあるクリームのように連続して這い上がる — 先端は実際にフレームごとに移動し、同じギザギザとした歯先が連続して登っていく。決して水平な階段状のブロック融解ではなく、瞬時の光の消散でもなく、明るい線のスイープワイプでもない。霜が薄くなるにつれて馬の形は自然に溶け消え、決して馬の形だけが溶けずに残ったり、ブロック全体が一瞬で消えたりすることはない。前線の背後では、濡れて輝くガラス面が広がり、水膜のハイライトが尾を引く。ラジエーターの上端は下端の温かい金属の帯としてのみ留まり、濡れたガラスの視認性が低下するにつれてその輪郭はぼやける — 決して変形してランプのように発光したり、ビーズ状になったりしない。このショットの終わりには、同じガラス面に水膜と形成された水滴が存在する。
SFX：柔らかな融解のヒスノイズ、初期の水滴のタップ音

0:07-0:09：同じ連続した濡れたガラス、同じ光。透明でほぼ丸い水滴が細い流れとなって重力で滑り落ちるか、軽く震えてから滑り落ちる — 軌跡は連続的であり、決して水の跡全体が一瞬で現れることはない。鏡のようなハイライトが水の流れとともに転がる。勢いは極めて遅いスライド＋ハイライトの微小な回転へと落ち着く。先端はほぼ停止するが、サブピクセルレベルの這い上がりが残る — 全編を通じて静的な印象に固まることを厳禁とする。新たな融解なし、再凍結なし。
SFX：水滴のタップ音 → 短い無音

0:09-0:10：同じ連続した濡れたガラス。光学ズームで最大 8% までのわずかなプッシュが透明な領域に食い込む。霜は不規則で有機的な残留先端と硬い濡れた縁を残し、下半分を横切る — 決して整った幅広い水平帯ではなく、楕円形の覗き穴でもなく、完全な馬の形のステッカーが残ることもない。残留した霜は、もはや完全な馬の形としては読み取れない。水蒸気越しにナトリウムランプの黄色く温かい街灯の光がはっきりと見える。温もりを感じたところで停止。
SFX：静かな部屋のノイズ

スタイル：リアルなマクロによるデコンプレッション（癒し）、濡れたガラスの物理挙動、冷と暖の対峙、ワンテイク。馬の群れはあくまで自然な霜の結晶によるシルエットの感覚として扱い、数えられる 7 頭の馬を追求しない。

ネガティブプロンプト：暖房開始前に溶けないこと。水平な階段状の融解禁止。明るい線のスイープワイプ禁止。瞬時の光の消散禁止。水滴や水の跡の瞬間的な出現禁止。融解後の乾いたマットガラス禁止。最終パートでのほぼ静止したフリーズ禁止。軸のジャンプ禁止。2 つ目の窓禁止。楕円形の覗き穴禁止。整った幅広い残留帯禁止。真鍮製バルブや配管部品禁止。ラジエーターがぼやけた街並みに変形すること禁止。ステッカー、アニメ調、彫刻による完全な馬の形禁止。融解中に馬の形だけが溶けずに残ること禁止。明確に数えられる 7 頭の馬の彫刻禁止。人の手、紅葉、木槌、偶像禁止。音楽やセリフ禁止。
```
